# Student Management System

A simple Python-based Student Management System for managing student records.

## Features

- Add student records
- View all student records
- Search students using roll number
- Handle invalid menu choices
- Interactive command-line interface

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- Basic Input Validation

## How It Works

The application provides a menu-driven interface where users can:

1. Add a new student
2. View existing students
3. Search for a student using roll number
4. Exit the application

Student information is stored using Python lists and dictionaries.
